# Сп'яніння — розширення для Owlbear Rodeo

Додає до контекстного меню персонажа пункт «Сп'яніння». Кожна позначка —
одна бульбашка над токеном, максимум сім. Колір бульбашок обирається
з палітри й зберігається окремо для кожного токена.

## Як влаштовано

| Файл                | Що робить                                                 |
| ------------------- | --------------------------------------------------------- |
| `src/background.js` | Реєструє пункт контекстного меню при відкритті кімнати.    |
| `src/popover.js`    | Кнопки «+», «–», «Зняти» і палітра кольорів.               |
| `src/common.js`     | Малює бульбашки: рахує розмір, позицію, чистить попередні. |

Стан (кількість і колір) лежить у метаданих самого токена, тож він
переживає перезавантаження і видно його всім у кімнаті. Бульбашки —
окремі елементи сцени, прикріплені до токена через `attachedTo`,
тому їздять і зникають разом із ним.

## Публікація

Репозиторій має називатися `bulbashky` — ця назва зашита в `vite.config.js`
та в адресах усередині `public/manifest.json`.

1. Settings → Pages → Source: **GitHub Actions**
2. `git push` — збірка й публікація відбуваються самі

## Встановлення

Профіль в Owlbear → Add Extension → посилання на манифест:

```
https://treyser.github.io/bulbashky/manifest.json
```

Далі створити кімнату й увімкнути розширення в діалозі створення.
